Kebijakan Privasi

Terakhir diperbarui: 9 Februari 2026

Terima kasih telah menggunakan Financial Privacy. Kami sangat menghargai privasi Anda. Kebijakan privasi ini menjelaskan bagaimana aplikasi kami menangani data Anda.

Financial Privacy adalah aplikasi yang sepenuhnya offline. Semua data Anda disimpan secara lokal di perangkat Anda dan tidak pernah dikirim ke server manapun.

1. Data yang Dikumpulkan

Aplikasi ini menyimpan data berikut secara lokal di perangkat Anda:

  • Data transaksi keuangan (judul, jumlah, tanggal, kategori, catatan)
  • Kategori transaksi
  • Target tabungan dan progress

Kami tidak mengumpulkan data pribadi seperti nama, email, nomor telepon, lokasi, atau informasi identitas lainnya.

2. Penyimpanan Data

Semua data disimpan menggunakan database SQLite lokal di perangkat Anda. Data ini:

  • Tidak dikirim ke server atau cloud manapun
  • Tidak dibagikan kepada pihak ketiga
  • Tidak dapat diakses oleh pengembang aplikasi
  • Sepenuhnya berada di bawah kendali Anda

3. Penggunaan Data

Data yang Anda masukkan digunakan hanya untuk:

  • Menampilkan ringkasan dan statistik keuangan di dashboard
  • Membuat visualisasi pengeluaran (pie chart)
  • Melacak progress target tabungan
  • Menghasilkan laporan PDF yang disimpan di perangkat Anda

4. Berbagi Data

Aplikasi ini menyediakan fitur export laporan ke PDF dan fitur berbagi. Ketika Anda menggunakan fitur ini:

  • File PDF dibuat dan disimpan secara lokal di perangkat Anda
  • Anda dapat memilih untuk membagikan file tersebut melalui aplikasi lain (WhatsApp, Email, dll.)
  • Pembagian file dilakukan atas inisiatif dan persetujuan Anda sendiri

5. Layanan Pihak Ketiga

Aplikasi ini tidak menggunakan:

  • Google Analytics atau layanan analitik lainnya
  • Layanan periklanan
  • Layanan pelacakan pengguna
  • Cloud storage atau sinkronisasi data

Aplikasi ini menggunakan Google Fonts (Poppins) yang mungkin diunduh saat pertama kali digunakan. Setelah itu, font disimpan secara lokal (cache).

6. Keamanan Data

Keamanan data Anda bergantung pada keamanan perangkat Anda. Kami menyarankan untuk:

  • Menggunakan kunci layar (PIN, pola, sidik jari) pada perangkat Anda
  • Menjaga perangkat Anda dari akses yang tidak sah
  • Melakukan backup data perangkat secara berkala

7. Penghapusan Data

Anda memiliki kontrol penuh atas data Anda:

  • Anda dapat menghapus transaksi individu kapan saja dari dalam aplikasi
  • Anda dapat menghapus target tabungan kapan saja
  • Menghapus (uninstall) aplikasi akan menghapus semua data secara permanen

8. Privasi Anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah 13 tahun. Kami tidak secara sengaja mengumpulkan informasi dari anak-anak di bawah 13 tahun.

9. Perubahan Kebijakan Privasi

Kami dapat memperbarui kebijakan privasi ini dari waktu ke waktu. Perubahan akan dipublikasikan di halaman ini dengan tanggal pembaruan terbaru. Kami menyarankan Anda untuk meninjau halaman ini secara berkala.
